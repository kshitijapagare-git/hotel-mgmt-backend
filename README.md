# hotel-booking-management

Spring Boot REST API generated by [Synth CLI](https://github.com/your-org/synth-cli).

## Requirements

- Java 21+
- Maven 3.9+
- Docker (for integration tests via Testcontainers)

## Quick Start

```bash
# Run the application (uses H2 in-memory DB by default)
mvn spring-boot:run

# Run all tests (requires Docker for Testcontainers)
mvn test

# Format code
mvn spotless:apply
```

## Error Schema

All error responses follow [RFC 9457 Problem Details](https://www.rfc-editor.org/rfc/rfc9457):

```json
{
  "type": "about:blank",
  "title": "Validation failed",
  "status": 400,
  "instance": "/api/resource",
  "errors": [
    { "field": "name", "message": "must not be blank" }
  ]
}
```

## Testing

Tests are split into two layers:

**Unit tests** (`*ServiceTest`) — pure service logic, Mockito mocks for repository, no Spring context.

**Integration tests** (`*ControllerIntegrationTest`, `OpenApiSmokeTest`) — full Spring Boot context with a real PostgreSQL instance via [Testcontainers](https://testcontainers.com). Docker must be running.

```bash
# Run only unit tests (no Docker needed)
mvn test -Dgroups="unit"

# Run all tests including integration
mvn test
```
## Message Broker

> **Limitation:** No message broker is configured for this project.
> Docker Compose and related infrastructure files are not generated.
>
> To add broker support, specify a broker in the Technical Context of your spec:
>
> ```
> **Message Broker**: kafka   # or: rabbitmq | redis
> ```
>
> Then re-generate the project. Supported brokers: Kafka, RabbitMQ, Redis.
